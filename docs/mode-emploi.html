Matheasy : mode d'emploi

Le panneau Matheasy s'ouvre à droite du document. En haut : les palettes et le champ de saisie. En dessous, trois outils repliés : Annoter, Graphique, Tableau. Clique sur leur titre pour les ouvrir. Matheasy se souvient, sur ton ordinateur, des outils que tu as laissés ouverts.

Matheasy a besoin d'une connexion internet au moment où on l'ouvre (l'interface d'ONLYOFFICE se charge en ligne). Sans connexion, un message rouge l'indique.

1. Écrire une formule

  1. Place le curseur dans le document, ouvre Plugins → Matheasy.
  2. Tape dans le champ, ou clique sur les boutons des palettes (Structures, Symboles, Grec, Analyse, Ensembles & logique, Fonctions, Probabilités).
  3. Clique sur Insérer dans le document : la formule arrive dans le document comme équation modifiable.
Touche Entrée : nouvelle ligne dans le champ. Chaque ligne devient un paragraphe du document. Idéal pour une résolution pas à pas.

2. Une résolution avec commentaires

Bouton + Commentaire : ajoute un texte à droite de la ligne (« on multiplie les deux membres par 6 »). L'écart et l'italique se règlent sous le champ.

3. Numéroter des exercices

Bouton + Exercice : ajoute une ligne de titre « Exercice 1 », puis « Exercice 2 »… Le numéro suit le nombre de titres déjà présents dans le champ. Le titre arrive dans le document comme texte ordinaire, la formule en dessous.

4. Cases à compléter (enseignant)

Boutons □/□ (fraction) et √□ (racine) : laisse les cases vides. Dans le document, l'élève clique dans la case et tape : la case disparaît.

Limite : une case vide n'existe qu'à l'intérieur d'une structure (fraction, racine…). Il n'y a pas de « trou » isolé.

5. Modifier ou compléter une formule existante

Je veux…Je fais…
Corriger une formuleSélectionne-la (ou place le curseur sur sa ligne), clic droit → Modifier avec Matheasy, ou bouton Modifier la formule sélectionnée. Change, puis Insérer : l'ancienne est remplacée.
Ajouter la solution sous l'énoncéCharge l'énoncé comme ci-dessus, Effacer, écris la solution, puis Insérer à la suite : l'énoncé reste, la solution s'ajoute en dessous.
Modifier toute une résolutionSélectionne toutes les lignes (elles se suivent), puis Modifier la formule sélectionnée.
RenoncerBouton Annuler du bandeau.
Si ONLYOFFICE refuse une des lignes au moment du remplacement, Matheasy annule tout : le document reste comme avant, sans doublon. Un message le signale.

6. Annoter (élève ou enseignant)

Ouvre l'outil Annoter la sélection. Sélectionne une partie de la formule dans le document, puis choisis une couleur ou Barrer. L'option « Couleur des lignes insérées » colore les nouvelles formules (bleu, vert, rouge) : pratique pour distinguer le travail de l'élève.

Encadré (palette Structures) : encadre la sélection du champ, ou toute la ligne si rien n'est sélectionné.

7. Graphique d'une fonction

  1. Écris la fonction sur la 1re ligne du champ, par exemple x^2-4 ou sin x. Une 2e ligne trace une seconde fonction g.
  2. Ouvre l'outil Graphique de la fonction. La courbe se trace toute seule ; règle l'intervalle avec x de … à ….
  3. Insérer le graphique dans le document : la courbe arrive comme image.
RéglageEffet
Case Afficher les zéros et les intersections calculés (décochée par défaut)Cochée : les zéros de f et g et les points où f(x) = g(x) sont marqués et écrits. Décochée : la courbe seule. À laisser décochée quand l'élève doit trouver lui-même les zéros ou résoudre l'équation. Vaut aussi pour l'image insérée.
Copier + ouvrir GeoGebraCopie la commande (ex. f(x)=x^(2)-4) et ouvre GeoGebra dans le navigateur. Colle-la avec Ctrl+V dans la barre de saisie.
Le traceur comprend les polynômes, fractions, racines, valeurs absolues, sin, cos, tan, ln, log, exp. Une équation qui n'est pas une fonction de x (cercle…) : passe par GeoGebra. Les valeurs affichées sont des approximations à 0,001 près.

8. Tableau de signes, de variations, Horner

  1. Place le curseur sur la ligne sous laquelle le tableau doit arriver.
  2. Ouvre l'outil Tableau avec traits, choisis le modèle et le nombre de colonnes (1re colonne = étiquettes x, f(x)… ; puis une colonne par valeur).
  3. Insérer le tableau : un vrai tableau du document, avec traits. Remplis ensuite les cases au clavier, ou avec Matheasy (curseur dans la case, puis Insérer).

La palette Fonctions fournit les signes utiles dans les cases : ↗, ↘, +∞, −∞, 0, +, −.

Limites connues

  • Les fractions écrites dans une ligne de texte sont affichées plus petites : c'est le comportement d'ONLYOFFICE.
  • Dans le champ du panneau, la sélection à la souris ne marche pas : clic droit → « Tout sélectionner ».
  • Pas de double-clic sur une formule du document pour l'ouvrir : utilise le clic droit ou le bouton « Modifier ».
  • Commandes non prises en charge par ONLYOFFICE : barré dans la formule (\cancel), couleur dans la formule (\color). Utilise l'outil Annoter, qui agit sur le document.
