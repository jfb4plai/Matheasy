Matheasy : installer le plugin

Matheasy est un plugin gratuit pour ONLYOFFICE Desktop Editors (Windows). Il permet d'écrire des formules de mathématiques comme dans MathType : fenêtre de saisie avec palettes, formules insérées comme équations ONLYOFFICE modifiables.

Installation (à faire une fois, puis à chaque nouvelle version)

  1. Va sur https://github.com/jfb4plai/Matheasy → bouton vert Code → Download ZIP.
  2. Extrais le ZIP (clic droit → Extraire tout).
  3. Dans le dossier extrait, ouvre tools et double-clique sur build-plugin.bat. Il crée le fichier dist\matheasy.plugin.
  4. Dans ONLYOFFICE : onglet Plugins → Gestionnaire de plugins. Si une ancienne version de Matheasy est présente, supprime-la.
  5. Clique sur Installer le plugin manuellement et choisis dist\matheasy.plugin.
  6. Ouvre un document (.docx), puis Plugins → Matheasy. Le panneau s'ouvre à droite.
Matheasy a besoin d'une connexion internet au moment où on l'ouvre : l'interface d'ONLYOFFICE pour les plugins se charge en ligne. Une fois ouvert, l'écriture des formules fonctionne sans connexion.
Une fenêtre Windows « Ouvrir avec » ou une erreur de script PowerShell ? Le fichier build-plugin.bat contourne déjà la restriction : utilise-le plutôt que le script .ps1.

Pour les élèves

Les élèves n'ont rien d'autre à installer que le plugin, et ONLYOFFICE. Les formules d'un document créé avec Matheasy sont des équations ONLYOFFICE ordinaires : elles s'affichent même sans le plugin, mais il faut le plugin pour les modifier avec la fenêtre Matheasy.
