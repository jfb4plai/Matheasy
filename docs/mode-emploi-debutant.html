Matheasy : écrire des mathématiques, pas à pas

Ce guide est fait pour toi si tu n'as pas l'habitude de l'ordinateur. Prends ton temps. Lis une étape, fais-la, puis passe à la suivante.

Avant de commencer. Il te faut le logiciel ONLYOFFICE et le plugin Matheasy déjà installé. Si quelqu'un l'a installé pour toi, tout est prêt. Sinon, demande de l'aide à la personne qui t'a donné Matheasy.

1. Ouvrir Matheasy

  1. Ouvre ONLYOFFICE.
  2. Ouvre un document (ou crée un nouveau document texte).
  3. Dans le menu du haut, clique sur Plugins.
  4. Clique sur Matheasy.
Une colonne apparaît à droite de l'écran. C'est Matheasy. Ton document reste à gauche.

2. Écrire ta première formule

  1. Clique dans ton document, à l'endroit où tu veux la formule. Un petit trait qui clignote apparaît.
  2. Dans la colonne de droite, clique dans le grand cadre blanc (le champ).
  3. Tape au clavier : 2x+3=7
  4. Clique sur le bouton bleu Insérer dans le document.
Ta formule apparaît dans le document. Le cadre blanc se vide tout seul : tu peux en écrire une autre.
Tu peux aussi cliquer sur les boutons en haut de la colonne (a/b, √, xⁿ…) au lieu de taper.

3. Faire une fraction

  1. Clique dans le cadre blanc.
  2. Clique sur le bouton a/b.
  3. Tape le nombre du haut (par exemple 3).
  4. Appuie sur la touche ↓ du clavier pour descendre en bas de la fraction.
  5. Tape le nombre du bas (par exemple 4).
  6. Pour sortir de la fraction et continuer à écrire à droite, appuie sur la touche →.
  7. Clique sur Insérer dans le document.
C'est la même idée pour la racine (√) et la puissance (xⁿ) : tape ce qu'il y a dedans, puis appuie sur → pour sortir.

4. Écrire plusieurs lignes (une résolution)

  1. Écris ta première ligne, par exemple 2x+3=7.
  2. Appuie sur la touche Entrée. Tu passes à la ligne suivante.
  3. Écris la suite : 2x=4. Puis Entrée, puis x=2.
  4. Clique sur Insérer dans le document.
Chaque ligne arrive l'une sous l'autre dans le document.

5. Ajouter une explication à droite d'une ligne

  1. Écris ta ligne, par exemple 2x=4.
  2. Clique sur le bouton + Commentaire.
  3. Tape ton explication : on enlève 3 des deux côtés.
  4. Clique sur Insérer dans le document.

6. Corriger une formule déjà écrite

  1. Clique sur la formule dans ton document (ou sélectionne-la).
  2. Dans la colonne de droite, clique sur Modifier la formule sélectionnée.
  3. La formule arrive dans le cadre blanc. Un bandeau jaune apparaît : c'est normal.
  4. Change ce que tu veux.
  5. Clique sur Insérer dans le document : l'ancienne formule est remplacée.
Tu veux garder l'ancienne formule et ajouter la suite en dessous ? Dans le bandeau jaune, clique sur Effacer (le cadre se vide), écris ta suite, puis clique sur Insérer à la suite.
Tu as changé d'avis ? Dans le bandeau jaune, clique sur Annuler.

7. Mettre en couleur ou barrer

  1. Dans ton document, sélectionne avec la souris la partie à colorer (ou à barrer).
  2. Dans la colonne de droite, tout en bas, trouve le cadre Annoter la sélection.
  3. Clique sur un rond de couleur (rouge, bleu, vert) ou sur Barrer.
Pour enlever la couleur : Sans couleur. Pour enlever le trait : Ne plus barrer.

8. Numéroter des exercices

  1. Clique sur + Exercice : « Exercice 1 » s'écrit sur une ligne.
  2. Appuie sur Entrée et écris la formule de l'exercice 1.
  3. Pour l'exercice suivant, clique à nouveau sur + Exercice : le numéro monte tout seul.
  4. À la fin, clique sur Insérer dans le document.

9. Préparer une case à compléter pour un élève

  1. Clique sur le bouton □/□ (fraction vide) ou √□ (racine vide).
  2. Ne tape rien dans les cases.
  3. Clique sur Insérer dans le document.
Dans le document, l'élève clique dans la case et tape : la case disparaît.

10. Ça ne marche pas ? Essaie ceci

Ce qui se passeCe qu'il faut faire
Rien n'apparaît dans le documentClique dans le document d'abord (le petit trait doit clignoter), puis refais « Insérer ».
La colonne de droite n'est pas làMenu Plugins → clique sur Matheasy.
Un message rouge s'affiche en basLis-le : il dit ce qui ne va pas. Prends une photo de l'écran et envoie-la à la personne qui t'aide.
Le bandeau jaune est restéClique sur Annuler.
Tu t'es trompé(e) dans le cadre blancClique sur Effacer et recommence.
Tu t'es trompé(e) dans le documentAppuie sur Ctrl + Z (retour en arrière).

11. Les boutons importants, en un coup d'œil

BoutonÀ quoi il sert
Insérer dans le documentEnvoie ce qui est dans le cadre blanc vers ton document.
EffacerVide le cadre blanc.
+ Ligne ou EntréeAjoute une nouvelle ligne.
+ CommentaireAjoute une explication à droite d'une ligne.
+ ExerciceAjoute « Exercice 1 », « Exercice 2 »…
Modifier la formule sélectionnéeReprend une formule du document pour la corriger.
Insérer à la suite(bandeau jaune) Garde l'ancienne formule et ajoute la nouvelle en dessous.
Annuler(bandeau jaune) Renonce à la correction.
Nouveautés en cours de test : le tableau avec traits (signes, variations), le graphique d'une fonction et le bouton GeoGebra. Ils sont en bas de la colonne. Tu peux les ignorer pour le moment.
